I’m Jatin Patidar, an independent cybersecurity researcher focused on discovering and responsibly disclosing vulnerabilities in web applications and APIs.

My research centres on access control, authentication, API security, IDOR/BOLA, rate limiting, and business-logic flaws. I enjoy understanding how complex web applications function under the hood, manually verifying security issues, and producing clear, deterministic technical documentation.

I continuously improve my practical skills through bug bounty programmes, PortSwigger Web Security Academy, Hack With Me, and hands-on laboratory research.

“I conduct security research within authorised scopes and responsible-disclosure programmes.”

Sensitive information, private credentials, customer data, and unreleased exploit details are strictly excluded from this portfolio.

05 / METHODOLOGY

How I Approach Security Research

A disciplined, non-destructive 6-stage research workflow combining passive intelligence, manual testing, deterministic validation, and responsible disclosure.

01
RECON

Passive asset discovery, DNS intelligence, historical URL discovery, and scope-boundary mapping.

02
UNDERSTAND

Application architecture, request flows, parameter handling, authentication states, and role hierarchies.

03
TEST

Deep manual testing with Burp Suite focused on application logic, state transitions, API behaviour, and access controls.

04
VALIDATE

Reproduction across isolated test accounts and controlled scenarios to reduce false positives and establish deterministic impact.

05
DOCUMENT

Clear, non-destructive proof-of-concept documentation, impact assessment, evidence, and remediation guidance.

06
DISCLOSE

Coordinated responsible disclosure through the designated security programme or reporting channel.
